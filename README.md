# 강윤성 | 소프트웨어 엔지니어링 포트폴리오

**데이터를 API·DB·모델로 연결하고, 실패 원인을 추적해 검증합니다.**

Python 기반 백엔드 개발과 AI 응용, 컴퓨터 비전 연구를 경험했습니다. 사용자 요청이 저장과 응답까지 이어지는 흐름을 구현하고, 필드·관계·상태를 나누어 오류가 발생한 지점을 분석합니다.

## 개발에서 중요하게 본 것

- **요청의 전체 흐름:** 인증 → 소유권 → 응답 생성 → 저장을 연결하고 각 단계의 책임을 구분했습니다.
- **데이터 계약:** API 스키마·ORM·관계 저장이 같은 의미와 필드명을 사용하는지 점검했습니다.
- **실패를 설명하는 평가:** 검출, ID 연결, 물리 ID 고정 기준을 나누어 측정값의 의미를 해석했습니다.

## 자료 안내

이 저장소는 프로젝트 설명과 공개 가능한 시각 자료를 모은 포트폴리오입니다. 개인 역할, 팀 화면, 코드로 확인한 구현, 기존 평가 기록의 범위를 각 상세 문서에 구분했습니다. 상담 공개 소스는 **응답 서비스 파일 1개**이며 전체 백엔드·학습 코드는 비공개입니다. MOT 수치는 기존 예측과 최신 GT의 재평가 기록으로, 새 추론 실행이나 성능 향상 수치가 아닙니다.
